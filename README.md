# segmentation-social-analyse# Social Segmentation Project

Projet Python de segmentation basé sur les variables :
- age
- revenu_mensuel
- score_interet
- frequence_activite
- nb_connexions_mensuelles
- temps_en_ligne

## Installation

```bash
pip install -r requirements.txt
```

## Exécution

```bash
python src/main.py
```
